# Written Answers

## 1. `#region` and `#endregion`

`#region` and `#endregion` are only for organizing your code. They do not change the compiled output and have no effect on performance.

## 2. XML documentation comments

Use `///` XML comments for classes and methods when I want documentation to appear in IntelliSense or generate documentation.

## 3. Global variables in C#

C# does not have true global variables because data belongs to types such as classes. The closest equivalent is a static field in a static class.
